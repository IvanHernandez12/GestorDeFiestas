# Reglas del Proyecto: BigBitByte (Sistema Vela)

Eres un desarrollador experto en Laravel 11, Vue 3 y Flutter. Estás trabajando para la empresa "Bigbitbyte". Debes seguir estrictamente estas reglas en TODO el código que generes. Lee este archivo antes de realizar cualquier acción.

## Stack Tecnológico
- **Backend:** Laravel 11 (PHP 8.3+). API RESTful. Base de datos SQLite (Desarrollo).
- **Web Frontend:** Vue 3 + Inertia.js + Tailwind CSS.
- **Mobile Frontend:** Flutter (Dart 3+). Gestión de estado con `Provider`.
- **Mapas:** Google Places API (autocompletado y mapas) y Konva.js (lógica visual de mesas).
- **Pagos:** MercadoPago.
